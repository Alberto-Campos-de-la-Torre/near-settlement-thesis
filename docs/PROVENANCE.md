# Project provenance and public release scope

This repository continues the same Investment Thesis project, **From clicks to settlement**. It is not an independent second project or a claim that all work originated in this account.

Source baseline: `5f6a14467a9b2394e395eecaf6b4bb1c9ed0eba6`, also published in [the upstream project](https://github.com/NGZeggers/near-value-shift). That project's development history begins on November 2, 2026. English presentation, reader navigation and subsequent quality corrections were prepared in a separate working copy before this public snapshot.

This release uses one clean `main` branch rather than importing a multi-project repository or its historical production materials. Original MIT licensing and contributor attribution are retained in `LICENSE`; the upstream history records earlier contributors. The snapshot date is not the original research start date.

The public tree contains source, tests, scientific data snapshots, SQL, frozen model artifacts and reproducibility documentation. Video/audio, subtitles, narration/storyboards, recording/export scripts, private configuration, credentials, private cloud project/job IDs, local paths and working caches are excluded. Recording materials remain outside the repository. Public blockchain account identifiers and public dataset names are scientific inputs, not wallet signing keys.

Private BigQuery execution IDs and project names are redacted in metadata/SQL templates; counts, timestamps, measured results, public source definitions and reconstructible queries are retained. Replace `your-project-id` and any result-table placeholders before new cloud queries. Offline judging requires no credentials or cloud access. The original receipt attestation and public on-chain logs remain byte-preserved.

This is a repository move for the same submission. Do not submit the project twice; if an existing application needs a different repository URL, use the organizers' human-reviewed change-request process.
