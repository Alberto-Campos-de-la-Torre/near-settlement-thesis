A reproducible investment thesis on NEAR

From clicks
to settlement

Is activity shifting from many low-value transactions to fewer, high-value cross-chain settlements through NEAR Intents, and does that show up in anything but the price? Every number on this page is computed by make build from committed snapshots, and every chart lists its source and query.

Reproduce it

Start from the submitted repository, rebuild its evidence, then inspect the same results locally.

You need Git, GNU Make, Python 3.12 and uv. The first setup downloads dependencies. The build uses committed snapshots; no wallet, Google account or API keys are required. Jupyter needs permission to open localhost ports.

  1. 01 Get the source

    git clone https://github.com/Alberto-Campos-de-la-Torre/near-settlement-thesis.git
cd near-settlement-thesis

    Use the repository and revision identified in the submission. Run the remaining commands from its root directory.

  2. 02 Install the locked environment

    uv sync --locked --all-extras --python 3.12

    Installs the analysis, notebook and testing dependencies. Keep uv.lock unchanged.

  3. 03 Rebuild the evidence

    make build

    Generates tables, models, charts, thesis, English review pages, the executed notebook and the local index. Existing committed research inputs are reused; this does not refresh data or send transactions.

  4. 04 Run the regression suite

    make test

    Expected: all tests pass, including pricing, receipt status, signing controls and English review-page navigation.

  5. 05 Verify reproducibility

    make check-generated

    Expected: generated artifacts match the checked-out commit, with exact text and hashes and only the declared numerical tolerance. A mismatch must be investigated, not silently overwritten.

  6. 06 Open the demo

    uv run python -m http.server 8000 --bind 127.0.0.1 --directory site

    Open http://127.0.0.1:8000/. Check filters, themes, chart tables, sources, the local thesis and notebook. Keep the terminal running; press Ctrl + C to stop the server.

The dashboard also opens directly from site/index.html. Keep the generated site/ folder together so its thesis, methods and notebook links work. First-time installation needs internet; the reconstruction itself runs from the committed snapshots.
